# DevByMaha - Developer Portfolio

![React](https://img.shields.io/badge/React-61DAFB) ![Vite](https://img.shields.io/badge/Vite-646CFF) ![CSS](https://img.shields.io/badge/CSS-1572B6)

Modern developer portfolio built with **React, Vite, and plain CSS**.

## Live Website

https://mahalakshmitetala.pages.dev/

## Features

- Light and dark theme toggle
- Responsive layout for desktop, tablet and mobile
- Scroll-reveal animations that respect the reduced-motion setting
- Project showcase with links to source code and live demos
- Skills section with technology icons

## Tech Stack

- React 19
- Vite
- Plain CSS (custom properties for theming)
- simple-icons
- Cloudflare Pages

## Preview Sections

- Hero
- About + Skills
- Selected Work
- Experience
- Contact

## Run Locally

```bash
git clone https://github.com/mahalakshmitetala/portfolio.git
cd portfolio
npm install
npm run dev
```

To create a production build:

```bash
npm run build
npm run preview
```
